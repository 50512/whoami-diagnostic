# Privacidad y manejo de datos

Este servicio muestra información que tu navegador o cliente ya envía al conectarse (IP, cabeceras, resolvers DNS). Aquí se describe qué se registra, por qué y por cuánto tiempo. El código es público, así que lo que dice este documento sobre el servicio se puede verificar en el repositorio.

## Lo que NO se hace

- No hay cuentas, cookies de seguimiento, analítica ni scripts de terceros.
- No se crean perfiles ni se asocia tu IP a una identidad.
- No se venden ni comparten datos con terceros.
- Las consultas de geolocalización (MaxMind GeoLite2) se hacen contra una base de datos **local**: tu IP no se envía a MaxMind.

## Qué hace el código (cualquier instancia)

| Componente                 | Datos                                                                              | Dónde y cuánto tiempo                                                                                   | Finalidad                             |
| -------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| API (log de acceso)        | IP de origen, fecha/hora, método, host, ruta (sin tokens), código de respuesta     | Solo en RAM (`tmpfs`), rotado a un máximo de ~20 MB. Se pierde al reiniciar o redesplegar el contenedor | Depuración y diagnóstico del servicio |
| DNS (log)                  | IP del resolver recursivo, tipo de consulta, fecha/hora                            | Solo en RAM (`tmpfs`), igual que la API                                                                 | Depuración del servidor autoritativo  |
| Redis (prueba de fuga DNS) | Token aleatorio de la prueba, IPs de resolvers, subred ECS si tu resolver la envía | Solo en memoria, sin persistencia, expira a los 60 segundos                                             | Mostrarte el resultado de la prueba   |

El modo de depuración (`LOG_LEVEL=DEBUG`) registra más detalle (consultas DNS completas, subred ECS, resultados de geolocalización). Solo se usa en desarrollo, nunca en la instancia pública.

## Instancia pública (diag.50512.dev)

Además de lo anterior, la instancia pública está detrás de un proxy inverso que protege toda la infraestructura donde se aloja. Ese proxy no forma parte de este repositorio:

| Componente             | Datos                                                                                                                                                                                | Retención                                                           | Finalidad                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- | --------------------------------------- |
| Proxy de borde (Caddy) | IP, fecha/hora, método, host, URI (con el token de la prueba DNS eliminado), código de respuesta, cabeceras de la petición (p. ej. User-Agent; `Cookie` y `Authorization` se omiten) | Rotación por tamaño; los archivos rotados se eliminan a los 14 días | Seguridad: detección y bloqueo de abuso |
| CrowdSec               | Solo IPs que disparan reglas de abuso (escaneos, fuerza bruta, etc.)                                                                                                                 | Lo que dure la decisión de bloqueo                                  | Bloqueo automático de tráfico malicioso |

Estos registros se conservan únicamente por el interés legítimo de mantener la seguridad del servicio y no se usan para ningún otro fin.

Si alojas tu propia instancia, eres responsable de lo que registren tu proxy y tu infraestructura.

## Notas

- **Resolver DNS:** normalmente es el de tu proveedor o uno público (Cloudflare, Google…). Si usas un resolver propio en casa (Pi-hole, Unbound), su IP puede coincidir con tu IP pública.
- **Intermediarios:** tu tráfico también pasa por terceros que este servicio no controla (tu ISP, tu resolver DNS), sujetos a sus propias políticas.
